# 第三章教学

\## 第一次Git实验总结 

1\. git add 的作用是： 把工作区里改动过的文件登记进暂存区，也就是先挑出"这次提交要包含哪些改动"。它不生成任何历史记录，只是把文件当前的内容拍个快照放进暂存区

2\. git commit 的作用是：把暂存区里的内容打包成一次永久的历史记录，存进本机 .git（本地仓库），并带上提交信息、作者、时间和唯一哈希值。commit 只写本地，不联网。

3\. git restore notes.md 的作用是：用暂存区里的版本覆盖工作区的 notes.md，丢弃你在这个文件上还没 add 的修改，也就是"撤销编辑、恢复成上次 add/commit 时的样子"。⚠️ 执行后手改的内容就没了，找不回来。

4\. commit 与 push 的区别是：commit 是本地操作，把改动记进本机 .git，不联网也能做，每提交一次就产生一个版本。

push 是联网操作，把本地已经提交好的 commit 上传到远程仓库（GitHub）​，别人或别的电脑才能看到。必须先 commit 才能 push。

一句话：commit 是"存档到本机"，push 是"把存档上传到服务器"。
